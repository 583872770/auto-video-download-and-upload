# 当前开发版本的数据合同

项目处于开发测试阶段，只维护当前表结构、配置格式和 Vue 界面。不提供旧版本数据升级、旧配置转换、旧角色别名或旧页面回退。

## 数据库初始化

运行环境要求 MySQL 8.4 或更新版本；SQLite 用于隔离测试。表结构唯一来源是 `webapp/database.py` 的 `metadata`。

首次启动创建当前表和索引。已有表启动前检查字段、具体存储类型、空值约束、主键、唯一约束和必要索引（含前缀长度）；MySQL 还检查 InnoDB 和区分大小写的排序规则。不匹配时返回明确的 `SchemaMismatch`，不会自动 ALTER、回填任务、重建计数或删除数据。多实例首次初始化仍使用 MySQL 命名锁，工作进程继续使用结构令牌跳过重复 DDL。

开发数据库结构变化后，应先备份，再明确安排重建测试数据库。程序不会替用户清空任务、素材、账号或账本。

## 本次结构整理

- ISO 时间字段统一为 `VARCHAR(40)`，任务历史直接按 `finished_at` 和序号排序，移除 `finished_order` 生成列及重复的状态时间索引。
- 将实例租约索引写入当前建表定义，避免新库依赖旧迁移程序才具备完整索引。
- 账号 Cookie 保留唯一索引，移除同列的普通索引；下载去重预留键直接使用主键索引。
- 删除历史升级记录表和账号别名设置。
- 下载去重使用任务队列的 `download_reservations` 表。已移除 `videos.txt` 归档导入和旧归档读写。共享 MySQL 的旧实例仍会在启动时校验 `download_archive` 表，待这些实例同步升级后可统一移除。
- 删除任务档案中不再生效的 `policy`、`policy_version` 列；实例策略版本和任务本次执行的策略快照继续保留。
- 删除执行会话表的旧单价和计费单位，会话仅记录执行统计；费用统一以任务中心交付账本为准。
- JSON 快照、错误详情、日志描述继续使用长文本；不把需要保留的审计和计费记录改为级联删除。

## 当前业务格式

- 服务角色仅接受 `hybrid`。实例只执行自己在工作台明确选择的客户任务，不继承全局旧选择。
- 下载固定使用 yt-dlp，不再维护按下载器分组的统计表；统计按任务与会话记录实际传输和交付。
- 账号 Cookie 使用 32 位 ID 和 `Cookies/profiles/<ID>.txt` 缓存路径。读取账号列表不会自动修改账号选择和配置。
- Cookie 分组不再解析旧浏览器导入名称中的时间后缀；人工停止状态使用当前版本保存的原因和事件编号，不回退旧记录格式。
- 字幕要求统一为 `original` 或 `original_and_translated`，缺少模式时使用当前默认原始字幕，不推断旧的指定语言模式。
- 前端必须先构建；资源缺失返回 503 和构建提示。旧模板、脚本和哈希路由不再作为第二套界面运行。

`scripts/migrate_mysql.py` 仅负责复制相同当前结构的数据库，不负责旧表升级。源库和目标库都应满足上述结构合同。
- 下载任务上限使用 `download_task_limit`，单文件分片使用 `fragment_concurrency`；没有总媒体连接预算，也不接受旧字段。
