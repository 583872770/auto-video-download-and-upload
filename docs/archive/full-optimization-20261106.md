# 下载系统全链路优化实施与验收（2026-11-06）

范围：落实 `full-pipeline-audit-20261106.md` 中的 12 个优化方向。目标是减少页面、队列和本地处理的浪费，并提供可判断的运行信息；不承诺固定比例的网络提速。

## 实施内容

| 位置 | 已实施 | 默认值／边界 |
| --- | --- | --- |
| 页面请求 | 读取超时、取消、失败退避；各数据块成功即渲染；同接口防重复；实例与参数变化时隔离旧响应 | 读取 12 秒、写入 90 秒；写超时提示结果待确认，不自动重发 |
| 实例页 | 非实例页跳过卡片生成；配置结构变化才重建表单，进度增量更新；保留编辑内容 | 实例页约 2 秒、其他页面约 5 秒；失败退避最多 30 秒；仍使用原实例 API |
| 大队列 | 新增 `(batch_id,status,seq)` 索引，候选和领取查询使用同一索引 | 领取权限、定向实例、延迟任务、公平性与租约检查保留 |
| 速度图表 | 成品时间增加规范 epoch 列及会话时间范围索引；30 点图表使用短缓存；兼容旧 ISO 写入 | 时间列迁移可重入，500 条一批；图表最多约 3 秒展示延迟 |
| 本地后处理 | 合并、搬移和相关媒体校验增加跨进程文件锁并发限额；记录等待、执行与清理耗时 | 默认 2，可在系统设置调整 1～8；等待期间继续报告进度、检查磁盘并维持原心跳 |
| 进度与速度 | 分别展示进度更新时间、最后字节变化、租约有效性；工作台和实例页不沿用超过 10 秒的旧瞬时速度 | 无新字节时不虚报传输；不会据此自动终止大文件；成品速度仍按账本统计 |
| Redis | 活跃任务批量 MGET；按 attempt、租约、时间和 SQL 检查点校验；增加错误、退避和拒绝原因指标 | MySQL 始终决定所有权；缓存失败退避 5 秒，每进程告警最多每分钟一次；指标是当前进程范围 |
| 只读 SQL | 账本总览短缓存；任务列表、工作台和实例汇总复用批量进度读取 | 不缓存领取、停止、冷却或租约最终判断；没有降低 MySQL 持久性 |
| 字幕 | 展示用状态计数短缓存；字幕向 OSS 上传也共享文件并发限额并检查磁盘 | 冷却截止与请求间隔仍实时读取；未新增字幕探测请求 |
| 日志 | warning 按会话失效、DRM 跳过、签名挑战等计数，保留原文；页面日志默认筛选本次服务启动后 | 不删除历史日志；原 API 默认仍可读取全部保留范围；日志继续脱敏和限量 |
| 流式导入 | 分块写入复用磁盘预留，按原租约机制节流检查 | 超出预留前仍先检查；持续写入至少每秒重检；磁盘不足仍中止 |
| OSS | 可配置同时文件数、每文件线程数、分片大小；记录耗时、重试、传输速度和真实字节变化时间 | 默认 2 个文件、每文件 2 线程、8 MiB 分片；断点续传、CRC、远端大小校验保留 |

新增配置位于“系统设置”：本地后处理并发在性能设置，OSS 三项在存储设置。正在执行的任务保持已领取的配置，后续任务读取新配置。

## 安全与执行边界

- 保留原 Cookie 单会话冷却、403 处理、启动间隔、yt-dlp 请求休眠和画质校验。
- 没有增加源站请求预算，没有通过更换账号补打 403。固定间隔模式未附带启用仅渐进模式使用的每小时／每日预算。
- Redis 与本地展示缓存不参与执行授权，缓存失败回退 SQL，旧 attempt 和过期租约不能覆盖当前任务。
- 后处理与 OSS 限额使用本机状态目录中的文件锁；进程退出会释放锁。降低配置不会中断已经开始的处理。
- 当前生产为测试下载模式，未向真实 OSS 写测试对象；没有用无活跃业务的功能测试冒充 OSS、浏览器或批量导入吞吐验证。
