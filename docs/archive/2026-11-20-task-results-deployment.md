# 任务中心统一文件、测试留样与观察

## 页面与保留规则

素材查看并入“任务中心 → 全部视频与文件”，独立素材库菜单、页面及专属组件已移除；交付和内部存储使用的底层接口保留。任务内“视频清单”分别显示执行状态、文件状态，结果详情逐项解释字幕、无声视频、纯音频、音视频成品、封面和视频信息的实际结果。本地、OSS、保留测试样本均可从这里查看；字幕可读全文，媒体支持 Range 预览和下载。

“测试样本与观察”支持快速清理与循环保留。默认每任务每实例最多 3 份、3072 MiB、24 小时，任一条件先到先回收；实例全部样本共用默认 3072 MiB 上限及 200 份硬上限，同时计入测试临时文件额度。空间紧张时优先回收旧样本，活动写入、待核对统计及查看中的样本受保护。留样移动本次已验证文件，不额外转码或请求源站。

页面支持验收通过、发现问题、延长 24 小时、手动清理和重新下载并留样。清理保留测试回执、累计统计与验收结论。单次重新留样沿用原交付要求和正常账号调度，受相同容量保护限制；快速测试也可单独重新留样。终态失败且没有活动写入、产物统计已登记的测试源文件默认最多保留 24 小时，空间压力下可提前回收；未登记统计或仍在排队重试的目录继续保护。

观察从本次启用开始记录，按小时保存最近 30 天最终结果和请求异常；异常明细定期收敛到 7 天、每实例最近 2000 条，页面展示符合筛选的最近 100 条。支持时间、账号和实例筛选；403、429、验证请求与最终失败分开，不能直接据此认定账号被风控。当前实时速度单独展示。

## 查询与预览修正

视频 ID 查询继续使用任务内或全局精确索引；保留样本筛选从小样本表定位任务，不逐行检查百万任务文件。列表只读一页并批量读取对应交付信息。

上线前在现有约 191 万条排队数据上发现：MySQL 将跨任务默认列表从任务配置表开始连接，产生全量临时排序，读取超过 60 秒仍未返回。修正为按任务顺序索引读取并在一页后停止，状态筛选使用状态与顺序索引。相同服务器的首批 51 条候选 SQL 实测约 3 毫秒；这是候选 SQL 时间，不能当作完整页面时间。

r56 上线检查中发现样本整理锁短暂占用时文件请求立即返回繁忙。r57 将预览改为有期限的等待，复用原锁最长 15 秒的限制；超时仍明确提示稍后重试。新增真实锁竞争测试，覆盖整理结束后直接读到文件，保留路径、权限、Range 与查看保护。
