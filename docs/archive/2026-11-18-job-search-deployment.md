# 任务中心视频查询优化与部署

## 变更

视频 ID 改为区分大小写的精确匹配，支持完整 YouTube 链接；标题关键词使用独立的 ngram 全文查询。移除 ID 前缀与标题包含查询混合的 OR 条件。

新增 `ix_tasks_job_video(batch_id, action, video_id, seq)` 和 `ft_tasks_title(title) WITH PARSER ngram`。列表先选最多 51 个 ID，只补充本页 50 条的数据与交付要求，批量读取进度，不加载任务汇总或下载配置；继续使用游标分页。

## 验证

- 前端 63 项测试、类型检查和生产构建通过。
- 浏览器验证精确链接、未命中、非法输入、标题查询、分页沿用已提交条件及手机布局，无脚本错误。
- Linux 候选镜像的任务、交付、查询及结构回归共 84 项通过。
- MySQL 独立测试库的查询与结构验证共 16 项通过，覆盖大小写、任务隔离、筛选、批量读取、中文 ngram、索引执行计划及结构重开检查。
- 本机扩展回归曾因缺少 `oss2` 和封面 MIME 断言失败；对应场景在完整 Linux 镜像中通过。本机 SQLite 的 500 万条验证仅用于检查索引读取量，未将其计为 MySQL 实测。

## 服务器实测

洛杉矶服务器 `216.227.169.90` 的实际任务包含 **1,971,451 条视频记录**。以下为服务器内部 HTTP 接口各采样 5 次的中位数，包含接口及数据读取开销，不包含用户到洛杉矶的网络延迟。

| 查询 | HTTP 中位耗时 | 采样最大耗时 | 实际匹配行数 |
| --- | ---: | ---: | ---: |
| 完整 ID 命中 | 11.92 ms | 19.45 ms | 1 |
| ID 未命中 | 7.62 ms | 10.31 ms | 0 |
| 完整视频链接 | 10.95 ms | 12.84 ms | 1 |

三种查询的 `EXPLAIN ANALYZE` 均使用 `ix_tasks_job_video` 定位，未全表扫描或额外排序。中文标题查询返回正常；不完整 ID 返回 400，提示输入完整 ID 或链接。
