# 下载工作台精简与刷新优化

## 页面调整

- 删除“视频处理进度”列表，视频状态集中在 Cookie 卡片展示；点击卡片内任务仍可查看详情与技术日志。
- 页面顺序为任务与下载控制、关键指标、Cookie 传输并发、成品产出趋势。
- 启动、完成当前后停止、立即停止集中在顶部，删除底部重复停止入口与工作流提示条。
- 保留任务搜索、实例切换、状态筛选、资源保护说明及移动端布局。

## 请求与渲染

- 工作台使用 `compact=1` 精简响应；默认 API 响应保持兼容。
- 实例列表只为所选实例计算详细并发诊断，其余实例仍提供基础运行数量与速度。
- 工作台响应只传汇总速度，省去重复的活动任务、正在下载视频及导入记录列表；速度样本超过 10 秒后显示待更新。
- 工作台常规请求约每 4 秒一次；并发状态保持约 2 秒刷新。仅请求当前页面需要的其他数据。
- Cookie 卡片、任务按钮及筛选框原地更新，保留焦点；任务集合不变时保留下拉选项节点；趋势数据不变时不重绘图表。
- 对客户端支持的 1 KiB 至 2 MiB JSON、脚本、样式及页面响应使用 gzip。跳过附件、范围请求、已有编码和普通流式响应；跨实例转发遵循客户端编码协商。

## 验证

- 工作台、实例及显示缓存回归：54 项通过。
- 压缩、精简接口、跨实例转发、任务及资源保护相关测试：51 项通过。
- `verify_workbench_performance_ui.py`：18 个 Cookie，验证布局、节点保留、筛选焦点、启停、任务详情日志、下拉选项与 360/390 像素移动端。
- 常规刷新采样 10.5 秒：实例接口 5 次、工作台接口 2 至 3 次、磁盘接口 1 次；没有请求隐藏的任务、素材、代理页面及全局 overview/status。
- `verify_concurrency_filters_ui.py`：混合任务、冷却账号仍传输、实例筛选偏好、过期/离线样本及移动端等场景通过。
- `verify_worker_control_ui.py`：资源保护与恢复说明回归通过。

以上为本地隔离环境验证，尚未部署。生产网络波动及数据库锁等待需另外观察，本次变更不代表这两类问题已解决。
