保留日志中，本期至少发现 135 次 `disk_pressure`，涉及 102 个任务；至少 418 次 `pipeline_backpressure`，涉及 371 个任务。日志会轮转，以上均为下限，不能与昨天保留日志的数量直接比较趋势。其中 pipeline 等待消息主要是 Cookie 账号并发/请求间隔控制，属于正常保护，不等于任务失败。

预算压力来自活动任务对未来空间和合并峰值的承诺，不能因为当前文件少就删除预算数据库或取消空间预留。80 GiB 也不能与十进制 GB 混比后判断超额。

建议调度前按预计峰值分配空间，让已启动的大视频优先完成；为大视频限制同时在途数量，等待空间时不要反复领取再中断。根据实际峰值、宿主机余量及吞吐再调整预算。当前吞吐仍在增长，不建议未经对比实验就把所有下载并发大幅降到固定值。
