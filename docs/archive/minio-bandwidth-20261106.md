每个对象为 8MiB 随机数据。每轮在前15秒启动请求，随后等待已开始的请求结束，实际整轮持续约18.88–28.53秒。速率按成功完整传输的字节总数除以整轮墙钟时间计算，包含连接、认证、服务端响应和末尾请求完成时间。上传以收到 MinIO 成功响应计入，下载以完整读取并核对对象大小计入。MB/s 使用十进制。

共六轮，均无请求错误。正式测速前上传、下载种子对象并验证 MD5 一致。5次 ICMP 采样平均往返延迟约180.14ms，未见丢包；该小样本不代表长期丢包率。

上传随并发明显提升，16连接测得约145Mbps；下载在本轮测试中增加到16连接没有继续提升，4连接约43Mbps。此结果仅代表本次两台服务器之间的真实对象传输，不能据此认定线路或单端网卡的硬性上限，也不代表阿里云 OSS 路线。

辅助观察：MinIO 主机已有其他容器业务，测试中一份快照显示 MinIO CPU 约0.79%、内存约309MiB；不足以精确归因瓶颈。发送端洛杉矶 TCP 拥塞算法为 cubic，MinIO 主机为 bbr，均保持原配置。
