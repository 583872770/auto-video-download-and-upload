# 并发诊断页面与优化策略

## 页面设计（已实现，待部署）

下载工作台的统计卡片与任务控制之间增加“并发与等待”，系统设置的多渠道区域复用同一组件。实例管理展示精简摘要。

第一层回答四个问题：设置多少路、当前准入额度估算多少路、实际传输几个视频、多少视频等待传输。准备与合并单独计数，不再把“处理中”解释成正在下载。

第二层按实际情况并列展示提示，不用一条“运行正常”覆盖其他阻塞：

| 状态 | 提示与操作 |
| --- | --- |
| 渠道上限低于实例并发 | 展示配置并发、单渠道上限及共享上游上限，前往下载策略 |
| HTTP 429 / 503 冷却 | 展示范围、已记录的触发阶段、剩余秒数；到期显示“等待状态更新” |
| 冷却后的恢复窗口 | 明确相关共享资源暂按 1 路放行，显示观察倒计时 |
| 临时空间等待 | 展示发布的预算原因，说明磁盘剩余容量与临时文件预算分别计算 |
| 全部实例总上限 | 展示全局额度，说明其他实例及准备阶段也占用 |
| 自动采样缺失或过期 | 展示保守额度及等待采样原因 |
| 暂停、离线或请求过期 | 展示停止领取或数据待确认，不把旧数据表示为可用额度 |

第三层展开渠道表：下载渠道、共享上游、渠道传输上限、解析方式、当前额度估算、共享占用、连接占用和冷却状态。相同资源组及在线实例遵守最小额度，多个入口不能直接相加。

当前额度是准入上界估算，不承诺始终占满。已有任务可以在额度降低后继续完成。手动 yt-dlp 在提取前预留传输与连接名额，页面因此说明“解析与传输共用名额”，不显示独立解析等待的错误结论。自动及第三方方式的实际分片连接数依媒体协议而定，不猜测固定连接占用。

接口只批量读取当前配置对应的资源键、有效租约持有的许可和磁盘摘要，不扫描任务日志或访问第三方网站。限流记录仅保存状态码和阶段，不保存异常原文或签名链接。UI 不更改调度、启动任务、清理文件或绕过限流。

## 已实现的调度调整（本地，待部署）

### 视频与字幕

`subtitle_mode` 默认 `optional`：本地保存的 yt-dlp 视频交付后，在视频完成事务中原子创建字幕任务。字幕有独立进程、独立共享许可和独立冷却范围，同时最多 1 个任务，开始时间至少间隔 10 秒。字幕 429 / 503 按 Retry-After 或默认 120 秒退避，视频渠道不因此进入冷却；字幕仍会消耗少量实际网络和磁盘资源。

字幕任务持久保存在现有任务队列，崩溃后可按租约恢复；暂停后不再领取，立即停止会终止正在执行的字幕任务。父视频详情提供字幕任务入口，显示待补、处理中或失败。字幕不参与视频交付计费；字幕失败不改变父视频成功结果。测试模式和第三方渠道不创建字幕补下载任务，视频文件已移除时直接跳过。

`subtitle_mode=required` 保持在视频任务内同步下载：至少存在一种所选语言，且所选可用字幕均成功写入后才完成；没有匹配字幕或写入失败则任务失败。此模式的字幕请求仍使用视频渠道的冷却保护。`off` 关闭字幕。`subtitle_languages` 默认 `en,zh-Hans,zh-Hant`，最多 8 个语言代码，不提供“所有翻译”批量请求。

### 并发配置与提示

| 设置 | 取值与语义 |
| --- | --- |
| `builtin_transfer_limit` | 0–64；0 保留原策略默认，顺序 / 分流 8，自动 32 |
| `builtin_connection_limit` | 0–128；0 保留原策略默认，顺序 / 分流 16，自动 64 |
| `builtin_resolver_limit` | 1–16，默认 4；手动 yt-dlp 不使用独立解析额度 |
| `download_connection_limit` | 本机媒体连接预算，默认 32，与共享预算同时约束 |

配置按实例保存并校验，后续领取的视频读取新策略。内置渠道分别使用这些额度；自定义渠道保留自己的上限，同资源组及在线实例取较小值。保存前实时提示“实例设 16 路，但单渠道最多约 8 路”等不一致，不自动扩大额度。

例如手动 yt-dlp 使用实例 16、渠道 16、本机连接 32、共享连接 32，可提供约 16 路准入上界；仍受全局额度、其他实例、冷却、空间和上游响应约束。既有自动吞吐控制继续按需求、接收速度和错误率调整，429 后退避再逐步恢复；本次没有承诺持续跑满 16 路。

### 临时预算与稳定性

磁盘页增加各分类“已用及预留 / 预算”。测试模式收集最近 24 小时最多 32 个成功任务的文件大小，至少 3 个样本后，以 90 分位峰值估算可支持的任务数和配置并发所需预算；yt-dlp 合并按成品大小两倍估算，最少采用初始预留大小。估算同时参考分类预算、总预算、其他分类占用和物理剩余空间，不自动修改预算，也不保证下一视频大小。多文件任务采用平均成品大小，样本变化会影响结果。

统计文件每次写入使用唯一临时路径，同进程进度计数加锁；统计写入失败限频记录监控警告，下载继续，恢复写入后保留内存中的累计值。数据库许可分配和释放统一先锁调度资源，再处理许可。对 MySQL 1205 / 1213 及 SQLite 锁等待最多重试 3 次完整事务；视频完成事务也使用相同重试。外部下载不在重试事务内，断开连接不盲目重试，字幕入队和视频统计随事务共同回滚。
