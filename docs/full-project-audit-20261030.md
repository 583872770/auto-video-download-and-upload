## 确认的问题与处理

| 等级 | 问题和触发条件 | 影响 | 当前处理及证据 |
| --- | --- | --- | --- |
| 高 | `app.py` 与 `app/` 包重名，启动和导入所需辅助模块不一致 | 部署激活时可能出现 `ModuleNotFoundError`，数据库已就绪但应用无法初始化 | 辅助模块移入 `webapp/`，修正导入与打包检查；24 个导入及打包启动检查通过 |
| 高 | 设置写入成功后，后续读回失败或值不一致仍可能清空草稿并显示成功；保存期间实例或表单可变化 | 用户看到保存成功，但页面回显与提交内容不一致，无法确认保存对象 | 固定所选实例、冻结表单、禁止缓存读回、比较提交字段，未确认时保留草稿；独立及混合实例浏览器验证通过 |
| 高 | 管理端转发 Cookie、预检、代理、磁盘等本地接口，接收端白名单却使用旧路径或错误 HTTP 方法 | 有页面入口，跨实例操作却被拒绝，返回实例认证错误 | 显式维护真实路径和方法协议，增加路由匹配及真实远端调用测试；人员角色与 CSRF 校验继续在管理端执行，共享任务和账户管理不向实例凭据开放 |
| 高 | 下载暂停标志在各进程缓存五秒，部分恢复/鉴权流程直接写数据库，无法清除其他进程缓存 | 停止或恢复成功后立即读取到相反状态，多页面结果不一致 | 移除该权限状态缓存，事务内直接读取；双 TaskStore 与暂停/恢复回归通过 |
| 高 | 自动调度先选中第二个适配器，方式统计却在领取时记给配置列表第一个 | 未使用的方式出现尝试或错误结果，实际下载的文件字节归类错误 | 自动模式在实际分配时登记；首选、切换、重试和完成回执恢复共用实际适配器选择逻辑；补充执行集成及统计测试 |
| 高 | 批量心跳参数包含执行者 ID，但 SQL 没有匹配执行者 | 旧执行者可以延长其他执行者的任务租约 | 批量更新同时匹配任务 ID 和执行者，重复任务和混合执行者也不会串用续期时长；本地与多实例契约通过 |
| 中 | 渠道统计切换只检查执行者，没有检查多实例租约过期和启动标识 | 失效执行者仍可能修改方式统计 | 与文件登记保持一致，拒绝过期租约和旧启动标识；过期执行者回归通过 |
| 中 | MySQL 领取先对共享预算行取共享锁，准入再请求独占锁 | 并发领取时锁升级可能导致不必要的死锁与重试 | 初始即取准入所需的独占锁，保留整体事务重试；SQLite 并发契约通过，实际 MySQL 验证仍需 CI / 独立测试库 |
| 中 | 素材路由把文件名任意位置的 `..` 当成穿越路径，且错误码与 API 契约不一致 | 合法的 `part..final.mp4` / 封面无法访问 | 检查独立父目录分量，仍校验解析后路径和扩展名；非法路径统一 404；合法双点文件名及 Range 播放回归通过 |
| 中 | 订阅地址仅验证首次 URL 与 IPv4 DNS 结果，默认跟随跳转 | 重定向或 IPv6 内网目标可绕过原检查 | 检查两种 IP 地址族、每次跳转、不可解析域名；真实 HTTP 跳转测试确认目标未被访问且原配置保留 |
| 中 | 旧验证脚本只输出勾叉且失败不设置退出码，使用持久目录；存储脚本仍依赖旧首页表单和已移除的网盘选项 | 脚本“完成”不能证明通过，或因界面已改版而误报 | 两个 P0 入口改为隔离行为测试并传播失败退出码；存储检查改为当前设置界面，并独立运行真实下载/清理后端契约 |
| 低 | 结构文档仍引用旧 `app.*` 包、暂停缓存及未接入运行器的批量心跳，并把估算性能当作实现结果 | 维护者按文档修改错误入口，容易再次造成断链 | 重写实际模块及调用链，旧优化文档增加明确更正，README 修正设置入口；自动策略日志不再声称严格按优先级执行 |

另外，统计会话 ID 保存在任务快照中，先前有直接从外层 payload 读取的路径，已统一通过快照解码；否则统计/恢复逻辑可能遗漏会话。相关交付登记、方式统计和磁盘恢复回归已覆盖。
