# 账号池共用启动间隔

入口：系统设置 → Cookie 与登录 → 会话并发、出口与请求节奏（高级）。修改“账号池共用启动间隔（秒）”后，统一点击“保存设置”。

配置键为 `youtube_cookie_pool_start_interval`，默认 10 秒，支持 0～600 的整数。只对 Cookie 账号池生效；同一实例的全部 Cookie 共用这一间隔，同时用于新视频分配和视频解析启动。0 关闭此项共用间隔。

每个账号自身的最小启动间隔继续由 `youtube_start_interval` 控制，并受预热、恢复、账号历史退避约束。账号并发、冷却、渐进模式的累计预算及 yt-dlp 等待预设仍分别生效。因此，设置为 0 不表示所有任务立即开始传输。

保存无需停止下载或重启。后续领取的任务使用新配置，已领取的任务保留原配置；已经预留的启动窗口不会因保存而取消。页面分别展示已保存的共用间隔与账号会话采样，不将配置值当成实测间隔。
