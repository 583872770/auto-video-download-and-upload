# 工作区页面职责

当前操作流程：任务中心新建任务 → 进入任务添加视频 → 下载工作台选择任务 → 开始下载。

| 页面 | 职责与主要操作 |
| --- | --- |
| 下载工作台 | 选择当前下载实例和已有任务，开始、暂停、停止仅控制当前实例；查看该实例的实时下载进度。 |
| 任务中心 | 新建任务资料；任务详情唯一的“添加视频”入口支持粘贴和文件导入。管理视频、失败重试、单价、账单和操作记录。 |
| 素材库 | 浏览、预览、下载与清理当前实例的成品文件。 |
| 交付与账单 | 汇总客户任务的实际交付与预计费用，查询和导出任务账单。下载器统计及历史执行会话折叠为次要内容。 |
| 执行日志 | 检索单个视频、导入和后台维护操作的执行结果与技术日志。客户任务不在这里创建或编辑。 |
| 下载实例 | 查看各实例下载策略，管理在线状态、启用 / 暂停、并发和运行资源；可进入所选实例的策略设置。 |
| 网络与代理 | 管理当前实例的连接方式、订阅、代理节点与轮换。 |
| 系统设置 | 当前实例的下载策略、目录、登录凭据、资源与日志。下载器顺序、画质等通过同一次“保存设置”提交。 |

主导航由共同模板渲染，工作台与任务中心使用相同名称、顺序和页面外壳。工作台、下载实例、素材库、网络与代理、系统设置共用当前实例选择；客户任务和账单仍全局共享。

系统设置只提交实际修改的字段。下载策略和保存方式只作用于所选实例后续领取的视频，正在执行的视频保留本次配置，其他实例不受影响。任务仅管理视频、资料与账单，不保存独立策略。素材清理期间，修改实际目录或保存方式仍会被拦截。

任务内“添加视频”是唯一的视频输入入口；首页、系统设置、新建任务窗口均不提供视频列表输入。任务创建和视频添加均不会自动开始尚未开始的任务。“前往下载”仅选择任务，开始下载仍需显式点击。

开始下载会按实例持久保存所选任务；刷新、重新打开工作台或切换实例时，恢复该实例最后启动的任务。不同实例可分别下载不同任务，也可共同处理同一任务。切换任务仅撤销当前实例的旧任务租约；暂停会让当前实例完成正在处理的视频，停止仅撤销当前实例的租约。下载实例页与工作台共用实例开关和任务选择，并显示各实例的实时视频、进度和速度，编辑配置不会冻结运行信息。全局并发上限、任务归档/删除和素材清空保护仍然生效。

下载工作台不再放置 Cookie 登录、实例策略编辑、重复素材预览和历史动态。任务归档与删除放在任务设置的独立折叠区域，日常操作区域保留添加视频和前往下载。任务单价以任务设置为准，移除全局默认单价的重复编辑入口。

已有任务与历史清单均使用执行实例自己的策略，旧任务策略记录保留但不再参与执行。原 API、账单、磁盘文件和历史记录不因页面调整而迁移或删除。

验证入口：`scripts/verify_workspace.py` 检查唯一输入入口、任务归属、下载控制、策略排序、统一导航和手机布局；`verify_jobs.py` 覆盖任务生命周期与权限；`verify_resume.py` 覆盖任务选择、系统停止、实例恢复及超时反馈。

`scripts/verify_selected_execution.py` 覆盖数据库恢复选择、两个浏览器与两个下载实例的任务切换、队列隔离、实时信息同步及手机布局。

## 界面布局与信息密度

任务中心是主导航首项与品牌首页，登录后进入客户任务列表。统一使用深蓝导航、浅灰背景与蓝色主操作；桌面导航宽 196px、顶部栏高 54px，内容留白收至 24px。正文保留清晰字号，依靠减少重复卡片和间距提高信息密度。

任务列表集中展示客户、状态、完成率、成功与失败、实际交付和预计费用；点击失败数量直接进入该任务的失败视频筛选。概览使用一条四项指标带，进度、当前执行、交付和导入记录按两列排列；处理完成率与已处理视频成功率分别展示。视频输入仍只在任务详情提供。

桌面下载工作台采用任务控制与实时进度两列布局，工作台交付指标仅显示所选任务，当前实例磁盘余量在顶部持续可见。实例监控汇总全部实例的在线数、执行量、传输速度与异常数；运行卡片并排显示，实例配置和全局运行设置默认折叠。展开配置或编辑输入时，实时状态持续刷新。

手机端保留导航与账户入口，指标改为紧凑网格；宽表格仅在表格内横向滚动，页面本身不产生横向溢出。实例停止、任务停止与全局运行设置保留明确作用范围。
