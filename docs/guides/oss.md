# 阿里云 OSS 保存

## 任务中心配置

1. 打开任务中心，进入具体任务的“任务设置”。
2. 在“本任务文件保存”选择“阿里云 OSS”。上传后继续保留本地副本。
3. 填写本任务的本地根目录、任务相对子目录和是否按视频 ID 分目录。
4. 填写 OSS Endpoint、Bucket、对象前缀、AccessKey ID、AccessKey Secret；临时凭据另需 STS Security Token。Endpoint 使用地域地址，如 `https://oss-cn-hangzhou.aliyuncs.com`，不包含 Bucket 名称；支持同地域内网地址。
5. 保存到当前任务。有在途执行时先暂停并等待结束，才能修改文件保存。

文件保存是任务配置；各执行实例使用此任务的规则，本地路径必须在实际执行机器上可用。OSS 上传并发、线程和分片参数也在任务内设置；上传并发由同一任务在同一实例内共用，各实例分别限额。

存储配置需要管理员修改。Secret 和 STS Token 不会由读取接口回显，留空保留已保存的值。凭据保存在服务端的任务配置中；任务执行不会从实例环境变量补充缺失凭据。CLI 的独立配置不作为页面任务的凭据来源。

使用具备对象上传、分片上传、列举分片及读取对象元数据权限的 RAM 凭据，基本权限为 `oss:PutObject`、`oss:ListParts`、`oss:GetObject`。素材预览和清空还需相应的读取、删除权限。应用不创建 Bucket、不更改访问权限、不生成公开访问链接。

## 文件组织与完成条件

本地文件结构为：

```text
根目录/任务相对子目录/[YouTube 视频 ID]/唯一文件名.ext
```

方括号目录仅在启用“按视频 ID 分目录”时存在。同一视频的视频、音频及多语言字幕放在同一目录；文件名含产物身份与唯一编号，避免重复执行互相覆盖。临时处理文件另行隔离，不在最终目录添加内部任务或执行编号层级。

OSS 对象为“对象前缀 / 本地文件相对于根目录的路径”。保存配置会固定到执行版本，已生成产物始终按其原版本的 Bucket、前缀和凭据访问；修改任务配置不会自动搬迁已有文件。

- 只上传任务要求生成的交付文件，本地副本继续保留，上传不会自动释放磁盘。
- 大文件使用分片与断点续传，上传后核对远端对象大小。
- 全部所需文件上传并校验成功后才确认交付；网络异常或校验失败按上传重试策略处理，授权或配置错误需修正后重试。
- 上传失败保留已验证的本地文件，重试可复用仍可访问且符合要求的产物。
- OSS 错误单独归类，不触发 YouTube 下载器切换，也不降低 Cookie 健康状态。
- 素材库的“清空本地素材”包含该实例登记的 OSS 原件；它不会列举并删除 Bucket 中未登记的其他对象。

## 验证

保存时校验参数格式与凭据是否存在，不提前连接 Bucket。首次下载后检查任务交付状态、素材预览和 OSS 控制台对象列表。失败时核对地域、Bucket、权限、凭据有效期与网络。

自动化测试使用模拟 OSS 接口，覆盖上传校验与重试、凭据隐藏、独立错误归类、按原任务版本预览以及不同 Bucket 的清理隔离。实际部署后仍需用目标 Bucket 验证上传、预览和删除权限。
