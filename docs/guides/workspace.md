# 页面与操作流程

日常操作从任务中心开始：创建客户任务、设置交付与文件保存要求、在任务内添加视频，再到下载工作台选择任务和实例并开始下载。新建任务和添加视频均不会自动启动下载。

## 页面与作用范围

页面顶部的范围栏区分“查看范围”“配置范围”“操作范围”，显示具体任务或实例。筛选列表不会修改配置，也不会把筛选条件作为批量操作目标；批量操作以勾选账号和弹窗显示的目标实例为准。

| 页面 | 作用范围 | 主要操作 |
| --- | --- | --- |
| 任务中心 | 全局查看、按任务配置 | 客户、任务资料、视频导入、交付要求、文件保存、单价和操作历史 |
| 下载工作台 | 所选实例 | 选择任务，开始、暂停、立即停止，查看账号阶段与等待原因 |
| 素材库 | 所选实例 | 按视频标题分组查看各任务素材，展开视频、音频和多语言字幕；导入、同步及清空 |
| 交付与账单 | 全局 | 汇总客户任务交付字节与预计费用，查询和导出账单 |
| 账号清单 | 全局 | 按实例筛选账号，批量登录、检测登录、分配实例，查看登录和冷却状态 |
| 账号池与请求节奏 | 所选实例 | 配置账号并发和请求启动节奏 |
| 下载实例 | 全局查看、按实例操作 | 实例状态、负载、并发与启停；全局并发上限单独标明 |
| 执行日志 | 全局查看 | 检索执行结果，按实际执行实例读取详细日志 |
| 网络与代理 | 所选实例 | 连接方式、直连源地址、订阅、节点和轮换 |
| 实例设置 | 所选实例 | 下载策略、并发渠道、空间日志、运行诊断 |
| 部署设置 | 所选实例 | 实例名称、地址、访问主机和连接检查 |
| 管理账户 | 全局 | 控制后台访问权限，与下载账号清单分开 |

## 实例设置与任务设置

实例设置入口为 `/settings`，包含“下载策略、并发与渠道、空间与日志、运行诊断”，默认打开下载策略。文件保存不在此处配置，也没有全局的新任务交付默认入口。

实例下载器顺序、画质、超时、重试、资源预算等配置由实际执行实例提供。保存按钮显示目标实例名称；切换分类保留草稿，切换实例或离开前处理尚未保存的修改。保存后仅该实例后续领取的视频生效，在途视频保留执行快照。运行诊断只读；账号池与请求节奏使用独立保存入口。

任务中心的“任务设置”管理本任务的资料、交付要求、文件保存和单价。文件保存可选择本地、OSS 或测试处理，设置根目录、任务相对子目录和按视频 ID 分目录。视频、音频和各语言字幕遵循同一目录规则。保存配置属于任务，所有执行此任务的实例使用相同规则；根目录必须在各执行机器上可用。修改不会搬迁已有文件，有在途执行时需先暂停并等待结束才能修改文件保存。

## 任务与实例控制

添加视频只在任务详情操作，支持粘贴 ID / 链接及 TXT / CSV 导入。“前往下载”只选择任务，开始下载仍需显式点击。刷新或重新打开工作台会恢复该实例最后成功启动的任务。

不同实例可以共同处理同一任务，也可处理不同任务。切换任务和工作台启停只控制当前实例；暂停让当前执行完成，立即停止撤销该实例租约并终止执行。任务中心中的暂停、停止、归档、删除和清空视频以该任务为范围，涉及其全部执行实例。操作弹窗显示具体对象。

详情见 [任务操作](tasks.md)、[交付要求](delivery.md)、[OSS 保存](oss.md) 和 [计费口径](billing.md)。

## 素材查看与清理

素材库按所选实例分页查询，以视频标题为组，展开后查看各类型文件及字幕语言。类型标签与数量按搜索范围内全部素材统计，不限于当前页。手动导入使用所选实例的默认素材目录，不采用某个任务的文件保存规则。

“清空本地素材”会删除当前实例登记的所有任务保存目录和默认素材目录中的内容，包括隐藏文件、孤立文件及分块目录；同时删除下载缓存、该实例登记的交付文件（含 OSS 原件）、关联执行日志、执行记录与产出统计。保留队列去重键。账号、实例设置、任务配置和其他实例数据不属于清理范围。

更换任务保存目录后，已登记的旧目录仍在清理范围。云端文件按产物生成时的任务配置定位，不会因当前 Bucket 改变而删错对象。清理前需暂停并等待下载、导入、索引结束，输入“清空”确认。文件删除、残留核验及记录清理全部成功后才显示完成；文件占用、权限或云端删除失败可修复后重试。

## 常见排查入口

- 下载慢或长期等待：查看账号阶段、等待原因和实例运行诊断，确认账号、渠道、连接、资源或磁盘限制。
- 登录失效：在账号清单登录或更新凭据，再检测登录；更新 Cookie 不会清除冷却。
- 文件缺项：在任务详情核对逐类型交付状态，补交或明确接受来源缺失。
- 视频失败：在任务详情或执行日志查看实际错误和已安排的重试。
