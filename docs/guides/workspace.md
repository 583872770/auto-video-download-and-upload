# 页面与操作流程

日常操作从任务中心开始：创建客户任务、设置交付要求、在任务内添加视频，再到下载工作台选择任务和实例并开始下载。新建任务和添加视频均不会自动启动下载。

## 页面职责

| 页面 | 主要操作 |
| --- | --- |
| 任务中心 | 客户、任务资料、交付要求、视频导入、失败重试、单价和操作历史 |
| 下载工作台 | 选择任务和实例，开始、暂停、立即停止，查看实时进度与等待原因 |
| 交付文件 | 按类型、语言、来源筛选，预览或下载字幕、音频、视频与成品 |
| 素材库 | 浏览、同步和清理实例本地素材，保留历史素材入口 |
| 交付与账单 | 汇总客户任务的交付字节与预计费用，查询和导出账单 |
| 账号管理 | 新增或导入账号、登录绑定实例、更新当前 Cookie、设置账号池与节奏 |
| 下载实例 | 在线状态、当前任务、并发、实时负载及实例启停 |
| 执行日志 | 检索单条来源和后台维护操作的结果、重试状态及技术日志 |
| 网络与代理 | 实例连接方式、直连源地址、订阅、节点和轮换 |
| 系统设置 | 实例下载策略、资源、存储和诊断；新任务默认交付要求 |
| 部署设置 | 实例名称、地址、访问主机和连接检查；Docker 连接信息由启动配置管理 |

## 系统设置与账号管理

系统设置保留四类：下载策略、并发与渠道、存储与清理、运行诊断。账号资料、Cookie 和启动节奏在“账号管理”单独维护；账号管理分为“账号清单”和“节奏设置”。

普通系统设置统一点击“保存设置”，账号池与节奏使用自己的保存入口。各实例分别保存配置；下载器顺序、画质、保存方式等用于后续领取或重试，正在执行的来源保留执行快照。新任务默认交付要求只影响之后创建的任务，实际客户要求保存在任务内。

切换实例前先处理尚未保存的修改。修改直连源地址、切换当前凭据或应用网络连接时，按页面提示停止当前实例并等待相关任务结束。

## 任务与实例控制

添加视频只在任务详情操作，支持粘贴 ID / 链接及 TXT / CSV 导入。“前往下载”只选择任务，开始下载仍需显式点击。刷新或重新打开工作台会恢复该实例最后成功启动的任务。

不同实例可以共同处理同一任务，也可处理不同任务。切换任务和工作台启停只控制当前实例；暂停让当前执行完成，立即停止会撤销该实例的租约并终止其执行。任务归档、删除和清空素材等操作以页面显示的作用范围为准。

任务资料、交付要求和单价在任务中修改，实例下载策略在系统设置中修改。详情见 [任务操作](tasks.md)、[交付要求](delivery.md) 和 [计费口径](billing.md)。

## 常见排查入口

- 下载慢或长期等待：先看“并发与等待”和运行诊断，确认账号、渠道、连接、资源或磁盘限制。
- 登录失效：在账号详情登录或更新凭据，完成后检测登录；更新 Cookie 不会清除冷却。
- 文件缺项：在任务详情核对逐类型交付状态，补交或明确接受来源缺失。
- 视频失败：在任务详情或执行日志查看已记录错误和实际安排的重试，不把建议重试等同于已排队。

验证入口为 `scripts/verify/verify_workspace.py`、`verify_selected_execution.py` 和 `verify_jobs.py`。历史页面原型只作设计参考，实际入口以本手册和运行页面为准。
