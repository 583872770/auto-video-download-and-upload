# 下载器

下载固定使用 yt-dlp，必须由实例账号池分配已登录的账号。没有匿名下载、第三方转换网站、渠道选择或自动回退。

在任务中心选择字幕、无声视频、纯音频、音视频成品、封面图、视频信息。交付要求、容器、字幕语言及保存路径属于任务配置。解析一次后复用音视频轨道，下载到的资源交给独立本地处理队列校验、转换及交付。

“单文件分片上限”同时用于普通 HTTP Range 和受支持的分片协议，范围 1～16；服务器不再按任务数除以总连接预算。范围响应或对象一致性验证不通过时安全退回单连接。分片上限不能保证源站提供对应数量的实际并发连接。

账号并发、账号启动间隔、账号池共用启动间隔、滚动启动预算和账号冷却由同一调度器执行。字幕、视频、音频和封面图使用同一套下载准入。

yt-dlp sleep 预设开启时：解析请求间隔 0.75 秒，每个媒体或字幕文件请求开始前等待 10～20 秒；它与账号任务启动间隔作用于不同位置。

Chromium 和容器桌面仅用于账号登录；FFmpeg/FFprobe 用于媒体处理与校验；Node.js 用于 yt-dlp 的 JS 挑战。没有浏览器下载并发或网页解析队列。
