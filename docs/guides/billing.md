# 交付统计与计费

客户任务是商业账单的归属单位。客户、任务名称、单价和单位在任务设置中维护；执行会话和下载器统计用于运行分析，不再单独设置商业单价或生成第二份账单。

## 核对流程

1. 新建任务时确认交付类型、语言、质量、单价及 GB / GiB 单位。
2. 在任务详情检查逐来源交付状态；“执行已完成”与“交付已齐全”分别显示。
3. 在“交付文件”核对可读取的正式文件，按类型、语言和来源筛选。
4. 在任务账单及“交付与账单”汇总大小和预计费用，导出 CSV 核对。

单价留空表示待定，0 表示免费。当前金额是预计费用，不包含支付、开票或正式结算冻结。多页面编辑冲突时先核对版本，不覆盖他人的最新修改。

## 字节与费用

正式交付按实际校验、成功发布的文件字节累计。字幕、音频、无声视频及音视频成品可分别交付，多语言字幕逐文件登记；共用原料的网络下载量与交付文件总大小是不同指标。

- 1 GB = 1,000,000,000 字节；1 GiB = 1,073,741,824 字节。
- 预计费用 = 实际交付字节数 ÷ 对应单位字节数 × 任务单价，使用十进制金额计算。
- 封面、元数据、中间轨道、失败残留和未发布的暂存文件不作为正式交付收费。
- 同一任务的相同语义产物通过账本去重，补交修复、重复回调或跨实例重试不重复收费；不同客户任务分别登记。

文件后续被删除或移动，不回写已发生的交付账本。历史任务沿用原有回执，不追溯补造字幕或音频费用。归档和删除任务保留的历史交付仍参与商业汇总。

## 测试与运行统计

测试模式在删除文件前登记实际完成字节，进入独立测试账本，不收费、不出现在正式交付文件页。失败或未完成的网络量不作为已完成交付量。测试转正式后需取得可发布的正式文件。

下载器统计按实际尝试归类，一个来源切换渠道会记录多个尝试，不能直接把尝试数当作客户视频数量。成功率、重试、等待和跳过也不能代替交付文件核对。历史缺少分类的记录保留为历史数据，不扫描旧队列补造归属或费用。

任务、文件和 CSV 明细使用分页或分批导出。具体交付要求、缺失确认和补交规则见 [交付说明](delivery.md)，来源管理见 [任务操作](tasks.md)。
