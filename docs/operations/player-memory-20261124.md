# r68 播放器解析与工作进程内存重构

## 问题与实现

旧版 `2026.11.15.232800.dev0` 在播放器 `b485e332` 上出现 `a.addOnDisposeCallback is not a function`，n/signature 解算失败后，最终错误被当成 DRM 内容限制。使用公开播放器源码、禁用网络的容器已复现旧版 main 变体失败。同一播放器的 tv 变体可解算。

升级并固定 yt-dlp `2026.11.23`，采用上游默认的 tv 播放器变体及相关提取修复；保留 Node v22.23.4、EJS 0.8.0。上游说明：<https://github.com/yt-dlp/yt-dlp/issues/18123>；默认变体修复提交 `fa9a87158bc6c1b8ec3e720fcb1c41e1ba62055d`。

应用区分明确的播放器解算故障与真实内容限制。只有先有解算失败、随后无法取得格式的任务才归为 `extractor_failure / player_challenge`，至少等待 60 秒并受任务尝试上限约束；不将这类故障归咎于账号，不触发账号或整个来源冷却。403、429、账号限流、明确私有/删除/地区限制仍按各自策略处理，真实 DRM 不变。页面通知显示中文原因及下一步。

内存生命周期重构：

- HTTP Range 每连接最多读取 256 KiB 后写入临时文件，Future 只返回偏移，不再保留整个 10 MiB 分块。网络读取不持文件写锁。失败或取消后先停止并等待所有写线程，再仅保留已验证的连续前缀，范围不兼容则清零后顺序回退。
- 下载器、提取器、Node provider 使用模块级类；每任务分别持有会话，关闭时清除播放器源码、prepared code、回调和会话引用。账号 Cookie 和 challenge 不跨任务共享，磁盘只缓存公开播放器代码。
- 每次任务结算完成后检查 RSS；较初始增长超过 32 MiB 才运行循环 GC 和 Linux `malloc_trim`。回收后仍高于 `max(256 MiB, baseline + 64 MiB)` 时结束该空闲进程，由现有调度器补槽。不会在活动传输途中回收或退出。

没有新增旧版本兼容分支，没有修改画质、交付类型、账号节奏、分片并发和任务槽位配置。

## 改前测量

r67，单独 600 秒窗口（候选测试与离线探针开始前）：宿主网卡接收 571.98 Mbps、应用媒体采样均值 608.56 Mbps；整机 CPU 75.97%、应用 CPU 64.91%、MySQL CPU 3.21%，以整机 4 核总容量为分母。工作进程配置 30；窗口内成功测试任务 100、失败 66。

部署前最终快照（候选测试容器已退出）：应用 Python 进程 USS 合计 8.65 GiB、PSS 8.67 GiB，整机可用内存 2.13 GiB，单进程最大 RSS 353 MiB。

## 验证与证据

本地 56 项回归通过，1 项平台相关跳过；依赖 `pip check` 和编译检查通过。HTTP 真服务测试包含流式落盘、乱序、重试、断点续传、取消、429、证书失败和顺序回退；另验证关闭下载器释放大对象、会话及回调。Linux 完整回归、真实 Node/EJS 离线 fixture 和部署后测量记录见同名服务器发布目录。

Linux 首轮执行 371 项回归，发现分块文件随机写入模式不受 yt-dlp POSIX 锁封装支持，已改用无追加/截断标志的文件描述符，取得独占锁后才清空新下载。最终 22 项 HTTP 回归全部通过，新增竞争写入者不能截断已有续传文件的验证。16 进程空间压力测试在 1 核配额中出现一次协调超时，单独给予 2 核配额后通过；空间管理代码未修改。其余回归沿用首轮通过结果，使用清单哈希确认只有 HTTP 实现及其测试有变化；合计覆盖 372 项，4 项跳过。未把首轮失败报告算作整套通过。

同一公开播放器 tv 变体连续 12 次 N/signature 解算，新版全部成功；不额外强制 GC 的末轮进程 RSS 约 76 MiB，旧版约 107 MiB。真实 Node 用例还覆盖无缓存/冷/热结果一致和损坏 prepared code 自动重建。main 变体仍可复现上游故障，因此采用上游修复后的默认 tv 路径。

部署保留实例、账号、配置和凭据摘要校验，未做数据库备份。首次切换因清单缺少 revision 中止并恢复 r67，补全元数据后成功部署 r68。六个页面、七个只读 API、26 个静态资源验证通过，线上 yt-dlp 为 `2026.11.23`；分片并发仍为 4，自动缩减关闭。

服务器证据目录：`/opt/frameflow/releases/player-memory-20261124-r68/`。本地证据目录：`.runtime/deploy/player-memory-20261124-r68/` 与 `.runtime/player-memory-20261124/`。
