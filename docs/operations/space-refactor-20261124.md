# 空间与下载流水线重构：部署观察

2026-11-24（北京时间）已部署 `youtube-downloader-app:pipeline-space-20261123-r67`，容器健康检查、页面、API 与静态资源验证通过。没有修改业务数据库结构、账号节奏、画质或交付类型。

## 实现

- 解析后统一生成源文件和输出计划，共享源只下载一次，按文件大小、码率与时长估计完成所需峰值空间。未知大小和估计偏差仍由运行检查处理。
- 下载和本地处理交接时保留完成承诺；产物登记并保存检查点后，释放不再需要的源文件与预留。单任务本身超过额度时明确失败，避免无限等待。
- 同源音视频拆分复用一次 FFmpeg 输入；可直接交付的渐进格式不预留整文件复制，HLS 保留重封装余量。无完整完成预留的后处理任务保有周转空间，领取前预判、实际准入和页面解释使用同一规则。
- 降低全量目录扫描频率，短暂空闲的工作进程复用，短阶段请求活动迁到 Redis。任务所有权、账号分配、启动预算和冷却仍保留 SQL 保护。
