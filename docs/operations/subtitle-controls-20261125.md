# 字幕范围、封面选择与网络阶段（2026-11-25）

## 行为

任务中心的交付配置分别设置原始字幕语言范围、来源优先级和自动翻译目标。
语言范围为视频主语言、指定语言或全部原始语言。默认保持全部原始语言，来源优先级和翻译设置不变。
主语言优先参考被来源明确标为 original 的音轨，其次使用语言元数据、唯一音轨语言或唯一原始自动字幕语言；不会用字幕列表第一项猜测。
无法确认主语言、指定语言没有原始字幕，均登记缺项并通过现有交付提醒展示。
原始语言选择不会隐式请求翻译，翻译目标单独配置。每种语言仍先人工、后原语言自动字幕，或按任务选择仅使用其中一种。

封面策略默认保持最佳画质优先。选择减少探测时，YouTube 仅使用提取器明确提供的原始封面地址，可能放弃推测地址上实际存在的更高分辨率图片；失效时明确登记缺项。
最佳画质仍按候选顺序回退，但同一任务已确认的 404/410 地址在实例本地缓存六小时，最多 2048 项；缓存只保存摘要。
不发送额外 HEAD 请求，不缓存 403/429，不将这类错误作为普通封面缺失回退。缓存无法写入不阻止下载。
缓存放在已有受管理的 `runtime/cache` 下，计入缓存用量并随清空本地素材一并清理。

## 网络观察

保留 yt-dlp 原生 sleep、重试、HTTP/HLS/Range 传输实现以及账号调度规则。
文件下载器的原生 `real_download` 边界代表文件等待结束，进入连接/首字节等待。
第一个比断点续传已有字节数更大的下载回调才进入真实传输；零字节或已有断点进度不会冒充传输。
文件启动等待显示原有截止时间；连接/首字节等待没有虚构倒计时；已有文件直接复用不计为网络传输。
统计 `network_seconds.interval/connecting/transferring`，其中 transferring 是首批数据回调到结束的可观测数据阶段，包含阶段内停顿，并非精确到网卡每次读操作的纯传输时间。
代理健康的传输耗时排除文件启动 sleep 和首字节等待。

阶段变化仍实时写 Redis。三种网络子阶段共用十秒 SQL 检查点，不因实时显示细分而逐子阶段强制增加数据库提交；后处理和终态仍持久化。

不清空任务，不缩减字幕语言，不更改请求间隔、账号并发或冷却。应用代码没有旧数据版本分支。
