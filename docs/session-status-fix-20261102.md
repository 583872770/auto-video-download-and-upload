## 原因及代码修复

- `Fleet.quarantine()` 自动隔离实例时只更新实例暂停和错误，没有调用会话停止逻辑。现在与手动暂停一样，将会话置为正在停止，最后一个在途任务退出后关闭；无在途任务时立即关闭。停止与领取共用准入锁，旧启动代次的检查结果不影响当前会话。
- `TaskStore._claim()` 在记录会话前使用数据库旧行的 `instance_id`，首次执行或跨实例接管时可能记入错误作用域。现在使用本次领取的执行实例记录会话。
