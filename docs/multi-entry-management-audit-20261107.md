# 多入口统一管理核查（2026-11-07）

## 结论与范围

现有架构支持每个实例同时提供管理页面和下载执行器。在 A 的页面选择 B 后，运行设置及本地资源操作应由 B 处理；客户任务、账单、账户等集群数据通过共享数据库管理。

本次在本地修复并验证跨实例管理中的配置、认证与页面切换问题，并按用户确认将部署设置、MySQL 和 Redis 连接纳入统一管理。未部署到生产。测试使用三个本地 HTTP 服务、同一 SQLite 数据库、独立配置及状态目录，没有启动实际下载 worker；这不是三台生产服务器共享 MySQL/Redis 的压力测试。

## 已修复的问题

1. 远程读取配置时，参数来自所选实例，但配置文件路径和相对素材目录使用了入口服务器的路径。现在完整配置响应由目标实例生成，并携带实例 ID；页面检查返回实例是否匹配。
2. Cookie“查看记录”已被转发，但节点认证白名单遗漏了对应接口，远程访问返回实例认证错误。现在只允许合法 Cookie ID 或 legacy 的 GET/HEAD，不开放写入或账户、账单等集群接口。
3. 切换实例读取失败后，旧实例的表单仍可操作。现在配置未就绪时锁定工作台、设置、代理和素材视图，同时阻止对应写请求，并提供“重新读取所选实例”。
4. A→B→A 快速切换时，只比较实例 ID 无法识别第一次 A 的迟到响应。现在所选实例请求同时检查切换序号，丢弃过期结果。
5. 所选实例失联或未登记时，实例列表刷新可能自动改选本机。现在保留明确选择并显示错误，不静默回退。
6. 代理订阅、轮换和 Cookie 上传草稿未完整纳入切换保护。现在检测这些草稿；所选实例的写请求尚未返回时也阻止切换。
7. 首次实例列表失败时，切换和重试处理器尚未注册。现在先注册交互与轮询，再读取列表，允许恢复后重试。
8. 工作台读取失败会连带锁定已成功读取的系统设置。现在工作台失败保留其错误状态，系统设置仍可操作。
9. 初次打开远程实例设置页时，Cookie 列表可能先读取默认本机。现在等待目标配置就绪后读取，并在切换后自动刷新目标 Cookie 列表。
10. “检查当前连接”转发到目标实例后仍检查全局队列，其他实例的工作会阻挡空闲实例。现在队列暂停状态、运行视频和已选任务的待处理量均按当前执行器判断；独立模式保留原有校验。

## 新增统一部署管理

导航中的“部署设置”现在位于运行管理页面内，与工作台使用同一实例选择器。支持实例名称、实例 ID、实例访问地址、允许访问的域名/IP、MySQL 地址/端口/库名/用户/密码，以及 Redis 开关和连接地址。

- 管理员权限在入口校验，目标使用仅限部署配置读取/测试/保存的节点 RPC；只读和操作员不能通过更换入口或目标越权读取、修改部署配置。
- 连接测试和保存前检查由目标实例执行。MySQL 使用独立短连接查询，Redis 使用有超时的 PING，不启动下载。
- MySQL 密码与 Redis 认证地址不回显；空密码/空 Redis 地址保留已有值，Redis 开关关闭则明确清除缓存连接。
- 使用配置版本防止多个页面相互覆盖，测试连接或原子写文件失败时保留旧配置；页面保留草稿，并可明确放弃修改重新读取。
- 配置写入目标状态目录下的 `deployment-managed.json`，文件仅由该目标持有。保存后提示待重启，当前应用与 worker 继续使用原连接；重启该实例后读取新 MySQL，并把 Redis 配置传给新应用及其 worker 环境。
- 显式通过统一页面保存后，该文件优先于 `.env`、启动环境和实例启动参数；没有此文件的部署保持原先从启动环境读取连接的行为。旧 `deployment.json` 中的历史数据库密码仍不自动启用，也不修改 `.env`。
- 本轮不提供容器重启、宿主机端口或挂载卷编辑；保存后需通过现有部署工具重启目标服务。目标启动失败时，仍保留独立访问码保护的 `/setup` 本机恢复入口。

## 操作范围

| 功能 | 处理范围 |
| --- | --- |
| 系统设置中现有的全部运行参数 | 所选实例，目标实例验证并保存 |
| 工作台选择任务、启动、完成当前后停止、立即停止 | 所选实例 |
| Cookie 库、上传、检查、导出、删除、记录、登录 | 所选实例 |
| 代理订阅、节点、轮换、测速和测试 | 所选实例 |
| 素材列表、播放、封面、重新索引及磁盘诊断/清理 | 所选实例的资源 |
| 执行日志 | 按任务实际所属实例读取 |
| 实例卡片参数与控制 | 卡片明确标识的实例 |
| 任务中心、客户、账单、管理账户、集群总览 | 全局共享数据 |
| 全局并发、旧的全局下载控制接口 | 集群范围，不能解释成当前实例开关 |
| 页面内“部署设置”（`/#deployment`） | 所选实例，包括 MySQL/Redis，保存后重启该实例生效 |
| `/setup` 本机部署恢复页 | 当前访问入口所在服务器，独立访问码，服务启动前也可使用 |
| Compose 端口/卷与容器重启 | 部署工具或部署文件 |

`/setup` 是服务启动前也可用的独立 WSGI 入口，不经过运行管理 API 的实例路由。新的统一部署管理使用独立的 `/api/instance-deployment` 接口，不冒用其他服务器的部署恢复访问码。

当前 `DEFAULTS` 中的运行参数均包含在实例本地字段或策略字段集合中；远程配置读取也不再依赖入口实例的默认值拼接。

## 仍需注意的现有边界

- 共享 MySQL/Redis 不代表服务器本地 HTTP、文件系统或浏览器可互相访问。每个实例需要独立且持久的实例 ID、状态目录、正确的 `VIDEO_INSTANCE_URL`，并且各入口都能访问所有目标实例；允许访问的域名/IP 和反向代理必须配置正确。反向代理需要保留实例认证头，各实例应使用一致版本。
- Cookie 当前绑定的是实例 ID。删除、离线不会自动解绑，但尚未增加物理服务器身份校验；不能据此承诺“复制同一个实例身份到另一台服务器也无法使用 Cookie”。该要求需要单独落实。
- 素材清空保留原有集群停止与清理互斥要求，不因为从其他入口操作而解除保护。
- 切换保护会阻止正在等待响应的页面写操作期间切换。网络超时不等于服务端撤销；失败提示后应读取目标状态确认实际结果。
