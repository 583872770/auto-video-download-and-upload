实例与访问

实例 ID 对应任务与 Cookie 归属，应保持稳定。实例地址填写其他服务器可访问的 HTTP(S) 地址；域名 / IP 用逗号分隔，不带协议和端口。

共享 MySQL

所有协作实例需连接同一个数据库。密码保存后不回显，留空保留原密码。

共享 Redis

页面保存的部署配置优先于启动环境，保存在目标实例状态目录；不会改写 .env。宿主机端口、卷映射和服务重启仍由部署工具管理。

服务无法启动时，直接访问目标服务器地址下的 /setup 本机部署恢复页，使用目标服务器的独立部署访问码恢复。
