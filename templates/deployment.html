02 / SHARED MYSQL
连接共享 MySQL
所有实例连接同一个数据库。支持 MySQL 5.7.9 及以上。

      

      
      
    

    
配置如何生效
首次保存后在后台初始化服务，完成后即可进入工作台；已经运行的服务修改后，重启本机服务生效。下载目录、Cookie、代理和并发仍在工作台中配置。
Docker 的宿主机端口与目录映射仍在 Compose 中设置。页面配置保存到本机持久化状态目录，优先于 .env 中的默认值。
